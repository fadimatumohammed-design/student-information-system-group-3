Student Information Management System

**Project Description**
The Student Information Management System is a simple web-based application developed to register students and display their records. It helps organize student information in one place.

**project objectives**
- To provide a form for registering students.
- To display registered student records in a table.
- To make student information easier to view and manage.

**Technologies Used**
- HTML
- CSS
- JavaScript
- Git and GitHub for version control and collaboration.

**Project Files**
- index.html – contains the webpage structure.
- style.css – controls the appearance of the webpage.
- script.js – handles the webpage functionality.
- README.md – contains project documentation.

**Collaboration Process**
Each member works on a separate feature branch named using their registration number. Members commit and push their changes to GitHub, then create pull requests for review before their changes are merged into the main branch.

Definition: A merge conflict occurs when Git cannot automatically combine changes made to the same part of a file in different branches.
One possible cause: Two team members edit the same lines of a file differently and then try to merge their branches.
